# TraverseLink 使用流程

TraverseLink 提供多站座標轉換、自動分區的區塊平差、GIS 成果檢視及 AutoCAD Script 匯出。以下僅說明目前版本的操作方式。

## 1. 開啟專案

開啟 `TraverseLink-CAD.html`，或目前使用的 `index.html` 入口。

- 新作業：新增測站並輸入資料。
- 繼續作業：按「載入專案」，選取先前儲存的 JSON。
- 試用：使用「載入範例資料」了解輸入與成果。

## 2. 輸入各測站相對座標

在測站切換列新增或選擇測站，設定站名，再將本站資料貼入測站窗格。

```text
點號,X,Y,Z,屬性
P01,0.000,0.000,10.250,控制點
P02,10.000,0.000,10.820,控制點
T01,5.000,5.000,10.900,EMHX
```

- 支援逗號或 Tab 分隔；屬性可省略。
- 跨站量到同一個實體點時，使用完全相同的點號，系統自動建立聯測關係。
- 點號區分大小寫。不同實體點不要使用相同點號，否則會被視為共同點。
- 不需手動切換 GPS 站或傳遞站。

## 3. 輸入專案共用 GPS

在測站窗格下方的「專案共用 GPS 控制點」貼入整份清單，只需貼一次。

```text
點號,E,N,H,屬性
P01,246440.000,2665050.000,52.250,控制點
P02,246450.000,2665050.000,52.820,控制點
```

各站依點號自動配對，測站窗格會顯示配對到的 GPS 點號。

- 同點號、相同座標組：只計一次，不增加權重。
- 同點號、不同座標組：相關區塊停止計算，需修正或手動刪除衝突列，不自動平均。
- 沒有任何測站觀測的 GPS 點，可作為 GPS-only 點列入合併匯出。
- 載入沒有共用 GPS 欄位的專案時，原各 GPS 測站清單會集中帶入。

## 4. 計算區塊平差

確認輸入預覽與診斷後，按上方「新增測站」右邊的「計算並查看結果」。程式統一使用區塊平差，全程固定 K＝1，不提供模式或比例切換。

### 判定測量區塊

只比較本站與前一站的全測站相對座標資料。至少有兩個不同點號的共同點，才連成同一區塊；只有一個或沒有共同點，就從後站開始新區塊，依序編為 B1、B2、B3……。重複列不算不同共同點，非相鄰站也不會跨越已切開的邊界重新連接。

某點即使也列在 GPS 清單，只要兩站都實際量到，仍可作為全測站共同點；只有 GPS 清單而沒有兩站觀測的點，不會建立聯測關係。

### 各區塊與 GPS 平差

| 區塊類型 | 計算方式 | 對外 RMS |
| --- | --- | --- |
| 獨立單站 | 本站直接與對應 GPS 控制點做 K＝1 套合 | 本站與 GPS 控制點的套合 RMS |
| 多站聯測 | 先用全測站觀測拼接及內部平差，再將整區塊與對應 GPS 套合 | 整個區塊與 GPS 控制點的套合 RMS |

內部聯測階段不使用 GPS 世界座標。GPS 控制點可分布在區塊內任意測站，不要求每一站都有 GPS；整區塊完成後，每個 GPS 點號只作一筆控制，不依測站數重複加權。高程只作整體位移。

每區塊至少需要兩個幾何上可定向的 GPS 控制點。資料無效、內部未收斂、共同點幾何退化或 GPS 不足的區塊會明確標示失敗，其他區塊仍可計算。摘要列出區塊編號、所屬測站、邊界共同點數、GPS 控制點及套合 RMS。

不同區塊的同名點分別保留，不互相覆蓋；區塊內同名點才合併。跨區塊不列為內部閉合差。修改資料後，舊成果會清除並提示重新計算。

## 5. 檢查成果與殘差

成果依序顯示「計算摘要 → 超限殘差檢核 → 合併座標與匯出 → 成果地圖 → 各站計算明細 → 詳細計算紀錄」。先檢查摘要與失敗訊息；各區塊皆以摘要中的 GPS 套合 RMS 檢查對外吻合。摘要會標示本次計算模式。

計算摘要統一顯示各區塊與 GPS 的套合 RMS，不重複顯示各站 RMS／SD 比較表。獨立站明細的 RMS／SD 表示本站與 GPS 的套合殘差；多站區塊的各站明細另列內部聯測 RMS／SD，兩者須分開判讀。

各站明細、殘差與詳細計算紀錄預設收合，需要時點開查看；失敗測站與群組狀態保持可見。E、N 與原有 X,Y 欄位皆保留。各模式原理與檢核門檻集中於設定區的「平差方法與精度說明」。

| 指標 | 意義 |
| --- | --- |
| 內部 RMS／SD、本站轉換 − 聯合座標 | 測站觀測與內部共同成果的吻合程度 |
| GPS 套合 RMS、聯合座標 − GPS | 區塊成果與 GPS 控制座標的吻合程度 |
| 3D | 三方向差值平方和開根號，單位公尺 |

預設提示門檻：小於 0.020 m 為良好；0.020 m 至未滿 0.050 m 為注意；0.050 m 以上需檢核。GPS 套合 RMS 也會影響測站狀態。

獨立站沒有跨站聯測指標，但仍有本站與 GPS 的套合 RMS／SD；不再因沒有聯測而顯示零或不適用。若本站與 GPS 確實完全吻合，套合 RMS 仍可能為零。有聯測的測站，其內部 RMS／SD 只統計跨站共同點，不混入單站 GPS 點或一般測點的零殘差。

內部誤差與 GPS 套合誤差應分開判讀。殘差代表資料吻合程度，不能直接當成實際定位精度。

### 殘差大於 0.020 m 的點

結果區直接列出超限明細，分成「GPS 殘差：聯合座標 − GPS」與「測站觀測殘差：本站轉換 − 聯合座標」。依未四捨五入的 3D 值嚴格大於 0.020 m 篩選，各類由大到小排列；剛好等於 0.020 m 不列入。

表格包含點號、測站、GPS 來源、ΔE、ΔN、ΔH、水平 2D 與 3D，單位公尺。同區塊同點號 GPS 在各站重複顯示的殘差合併為一筆，不同區塊分列並標示區塊編號，保留相關測站與來源；測站觀測逐站保留。可下載「超限殘差 CSV」，HTML 報告也會包含明細。載入已計算專案時會重建清單。

此清單不自動剔除資料。最右側「停用 GPS／啟用 GPS」作用於整份共用 GPS 清單；「停用本站觀測／啟用本站觀測」只作用於該站該點。切換後自動重算並顯示完成訊息，鍵盤焦點回到同點操作；若該點不再列入清單，則回到殘差區。停用列保留停用前殘差並以不同底色區分，操作欄固定在表格右側，便於橫向捲動後操作。

停用可能使測站區塊分開或控制點不足。內部聯測良好、少數 GPS 明顯偏離時，可優先檢查這些 GPS；若同點的測站觀測也不一致，應先核對點號與原始觀測。詳細說明收合於「停用範圍與重算說明」。

確認需停用某點 GPS 時，先保留一份原專案，再從共用 GPS 清單移除該點所有 GPS 列，保留各站對該點的實際量測資料並重新計算。檢查其餘控制點的殘差、分布與定向條件；保留幾何模式每群組至少需兩個可定向的 GPS 點，僅達最低條件不代表具有足夠的錯誤辨識能力。請記錄排除原因，避免只為降低殘差反覆刪點。

## 6. 檢視 GIS 地圖

地圖顯示目前所選模式計算出的成果。使用右上角圖層控制切換底圖：

| 底圖 | 來源 |
| --- | --- |
| 台灣通用電子地圖（預設） | 國土測繪中心 EMAP |
| 正射影像 | 國土測繪中心 PHOTO2 |

- 底圖擇一顯示，不改變成果座標。
- GPS+EDM、GPS-only、EDM 點位圖層可分別開關。
- 同一頁面期間重建地圖會保留底圖選擇；重新開啟頁面回到電子地圖。底圖選擇不存入專案 JSON。
- 底圖與外部地圖套件需連網；座標計算在本機瀏覽器執行。

## 7. 匯出與儲存

| 操作 | 輸出內容 |
| --- | --- |
| 複製各站／合併 TSV、下載合併 CSV | 本次區塊平差成果；可帶入 Excel 等後續作業 |
| 下載 HTML 報告 | 本次所選模式成果，並標示模式 |
| 儲存專案 JSON | 共用 GPS、測站資料、區塊平差設定與本次成果、CAD 輸入與已套用的自訂對照等專案狀態 |

CSV／HTML 檔名含 `geometry_K1`。專案 JSON 保留原始輸入、區塊資料與當次成果。載入舊版區塊平差存檔時，可由已存的 GPS 套合資料還原獨立站 RMS；載入舊共同協調成果時只還原輸入，需按「計算並查看結果」重算，不混用舊算法成果。

## 8. 匯出 AutoCAD Script

切換至「AutoCAD Script 匯出」，依需求貼入控制點與孔蓋資料。CAD 輸入使用實際貼入的資料，不會自動被所選平差模式的成果替換。

```text
控制點：點號 X Y Z
CP01 246440.000 2665050.000 52.250

孔蓋：點號 X Y [Z] Code
MH01 246445.000 2665055.000 52.100 EMHX
```

1. 確認目標 DWG 已有對應圖塊，並使用相同座標分帶與公尺單位。
2. 檢查 Code 對照與格式提示；需要時使用「Code 對照設定」展開編輯並套用，再按同一按鈕收合。格式錯誤與略過筆數會持續顯示在檢查摘要及匯出區。
3. 下載 `.scr`，儲存圖面後再於 AutoCAD 執行。

常用預設對照：`EMHX → 12-N-E`、`UMH → 20`、`UHH → 30`、`WMH → 98`、`CP → CPT`。

控制點及 `12-N-E` 圖塊以 X、Y 定位，點號與高程寫入 `CPTNAME`、`CPTELEV`。`98` 圖塊使用 0.5 插入比例。未對應 Code 會提示並略過，請先檢查再匯出。

已套用的自訂對照會嘗試儲存於目前瀏覽器；專案 JSON 另保留專案對照及編輯內容。


## 控制點品質管理

- GPS 清單中的有效資料全部作為套合控制點，格式為 `點號,E,N,H,屬性`。需排除時直接手動刪除該列，不提供控制／檢核／停用分類或原因欄位。
- 舊專案第六欄以後的用途與備註不再影響計算；原檢核、停用點若仍保留在清單內，也會參與套合。舊分類成果匯入後需重新計算。
- 同點號不同座標不再平均。相關區塊停止計算，修正或手動刪除衝突列後再算；其他區塊可繼續。
- 不另顯示 GPS 品質說明或控制點幾何提示，使用者依區塊套合 RMS、各站 RMS 與逐點殘差進行人工審核。
- 平面座標系統固定為 TWD97 / TM2 121，高程基準固定為正高 TWVD2001，單位為公尺；畫面不需選填，專案與報告均記錄固定基準。所有輸入資料應使用此基準。
- 現行方法為座標式聯測平差＋GPS 套合；殘差 SD 是描述統計，不是成果座標標準差。未加入原始角距觀測量、精度權重或協方差估計。

上方「測站區塊」與計算共用同一套分區邏輯：不同區塊分框顯示，只有同區塊相鄰測站才顯示雙向連線與共同點數。`CP test.xlsx` 範例應為 B1＝EDM1、B2＝EDM2、B3＝EDM3＋EDM4；後兩站共同點為 A45、B45、C45。
