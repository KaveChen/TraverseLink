# TraverseLink 使用流程

TraverseLink 提供多站座標轉換、雙解平差、GIS 成果檢視及 AutoCAD Script 匯出。以下僅說明目前版本的操作方式。

## 1. 開啟專案

開啟 `TraverseLink-CAD.html`，或目前使用的 `index.html` 入口。

- 新作業：新增測站並輸入資料。
- 繼續作業：按「載入專案」，選取先前儲存的 JSON。
- 試用：使用「載入範例資料」了解輸入與成果。

## 2. 輸入各測站相對座標

在測站切換列新增或選擇測站，設定站名，再將本站資料貼入測站窗格。

```text
點號,X,Y,Z,屬性
P01,0.000,0.000,10.250,控制點
P02,10.000,0.000,10.820,控制點
T01,5.000,5.000,10.900,EMHX
```

- 支援逗號或 Tab 分隔；屬性可省略。
- 跨站量到同一個實體點時，使用完全相同的點號，系統自動建立聯測關係。
- 點號區分大小寫。不同實體點不要使用相同點號，否則會被視為共同點。
- 不需手動切換 GPS 站或傳遞站。

## 3. 輸入專案共用 GPS

在測站窗格下方的「專案共用 GPS 控制點」貼入整份清單，只需貼一次。

```text
點號,E,N,H,屬性
P01,246440.000,2665050.000,52.250,控制點
P02,246450.000,2665050.000,52.820,控制點
```

各站依點號自動配對，測站窗格會顯示配對到的 GPS 點號。

- 同點號、相同座標組：只計一次，不增加權重。
- 同點號、不同座標組：不同組各取一次，平均形成一筆控制座標，並提示差異。
- 沒有任何測站觀測的 GPS 點，可作為 GPS-only 點列入合併匯出。
- 載入沒有共用 GPS 欄位的專案時，原各 GPS 測站清單會集中帶入。

## 4. 計算兩種成果

確認輸入預覽與診斷後，按輸入區底部唯一的「計算並查看結果」。系統會同時計算兩種方法，並定位至結果摘要。

| 項目 | 主要成果：保留內部幾何 | 參考成果：共同協調 |
| --- | --- | --- |
| 計算方式 | 先不使用 GPS 做內部聯測，再將各群組整體套合 GPS | GPS 與各站觀測同時參與平差 |
| 水平比例 | 全程固定 K＝1 | 依參考解設定，固定或開放比例 |
| GPS 作用 | 整體平移、旋轉與高程位移，保留內部平差完成後的幾何 | 以軟約束參與求解，可影響內部相對關係 |
| 獨立站 | 各自與對應 GPS 套合 | 各自與對應 GPS 求解 |
| 一般表格、地圖與座標匯出 | 使用主要成果 | 另列為參考與比較 |

主要成果的內部聯測須有足夠共同點建立定向；單一共同點不能獨立決定兩站的相對旋轉。每個群組也需要至少兩個幾何上可定向的 GPS 控制點，才能整體套合至世界座標。

若某群組無法初始化、未收斂或缺少可用 GPS，會標示主要解失敗，不以參考解代替；其他可解群組仍會產生成果。

修改已計算的資料或比例設定後，需重新計算。

## 5. 檢查成果與殘差

先檢查計算摘要、失敗訊息與群組 GPS 套合 RMS，再查看各站、合併表及雙解比較。

| 指標 | 意義 |
| --- | --- |
| 內部 RMS／SD、本站轉換 − 聯合座標 | 測站觀測與內部共同成果的吻合程度 |
| GPS 套合 RMS、聯合座標 − GPS | 主要成果與 GPS 控制座標的吻合程度 |
| 雙解 ΔE、ΔN、ΔH | 共同協調參考座標減去主要座標 |
| 3D | 三方向差值平方和開根號，單位公尺 |

預設提示門檻：小於 0.020 m 為良好；0.020 m 至未滿 0.050 m 為注意；0.050 m 以上需檢核。GPS 套合 RMS 也會影響測站狀態。

內部誤差與 GPS 套合誤差應分開判讀。殘差代表資料吻合程度，不能直接當成實際定位精度。

## 6. 檢視 GIS 地圖

地圖顯示主要成果。使用右上角圖層控制切換底圖：

| 底圖 | 來源 |
| --- | --- |
| 台灣通用電子地圖（預設） | 國土測繪中心 EMAP |
| 正射影像 | 國土測繪中心 PHOTO2 |

- 底圖擇一顯示，不改變成果座標。
- GPS+EDM、GPS-only、EDM 點位圖層可分別開關。
- 同一頁面期間重建地圖會保留底圖選擇；重新開啟頁面回到電子地圖。底圖選擇不存入專案 JSON。
- 底圖與外部地圖套件需連網；座標計算在本機瀏覽器執行。

## 7. 匯出與儲存

| 操作 | 輸出內容 |
| --- | --- |
| 複製各站／合併 TSV、下載合併 CSV | 主要成果；可帶入 Excel 等後續作業 |
| 下載雙解比較 CSV | 主要與參考座標、參考減主要差值 |
| 下載 HTML 報告 | 主要成果與雙解比較 |
| 儲存專案 JSON | 共用 GPS、測站資料、兩種成果、CAD 輸入與已套用的自訂對照等專案狀態 |

主要 CSV 檔名含 `primary_geometry_K1`。載入專案後可檢視與再次匯出；載入沒有雙解成果的專案時，重新計算後才會產生目前的兩種成果。

請使用目前版本頁面開啟共用 GPS 與雙解格式的存檔。

## 8. 匯出 AutoCAD Script

切換至「AutoCAD Script 匯出」，依需求貼入控制點與孔蓋資料。CAD 輸入使用實際貼入的資料，不會自動被主要或參考成果替換。

```text
控制點：點號 X Y Z
CP01 246440.000 2665050.000 52.250

孔蓋：點號 Code X Y [Z]
MH01 EMHX 246445.000 2665055.000 52.100
```

1. 確認目標 DWG 已有對應圖塊，並使用相同座標分帶與公尺單位。
2. 檢查 Code 對照與格式提示；需要時開啟「管理自訂對照」並套用。
3. 下載 `.scr`，儲存圖面後再於 AutoCAD 執行。

常用預設對照：`EMHX → 12-N-E`、`UMH → 20`、`UHH → 30`、`WMH → 98`、`CP → CPT`。

控制點及 `12-N-E` 圖塊以 X、Y 定位，點號與高程寫入 `CPTNAME`、`CPTELEV`。`98` 圖塊使用 0.5 插入比例。未對應 Code 會提示並略過，請先檢查再匯出。

已套用的自訂對照會嘗試儲存於目前瀏覽器；專案 JSON 另保留專案對照及編輯內容。
