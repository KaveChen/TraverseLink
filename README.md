# TraverseLink 使用流程

TraverseLink 提供多站座標轉換、兩種可選平差模式、GIS 成果檢視及 AutoCAD Script 匯出。以下僅說明目前版本的操作方式。

## 1. 開啟專案

開啟 `TraverseLink-CAD.html`，或目前使用的 `index.html` 入口。

- 新作業：新增測站並輸入資料。
- 繼續作業：按「載入專案」，選取先前儲存的 JSON。
- 試用：使用「載入範例資料」了解輸入與成果。

## 2. 輸入各測站相對座標

在測站切換列新增或選擇測站，設定站名，再將本站資料貼入測站窗格。

```text
點號,X,Y,Z,屬性
P01,0.000,0.000,10.250,控制點
P02,10.000,0.000,10.820,控制點
T01,5.000,5.000,10.900,EMHX
```

- 支援逗號或 Tab 分隔；屬性可省略。
- 跨站量到同一個實體點時，使用完全相同的點號，系統自動建立聯測關係。
- 點號區分大小寫。不同實體點不要使用相同點號，否則會被視為共同點。
- 不需手動切換 GPS 站或傳遞站。

## 3. 輸入專案共用 GPS

在測站窗格下方的「專案共用 GPS 控制點」貼入整份清單，只需貼一次。

```text
點號,E,N,H,屬性
P01,246440.000,2665050.000,52.250,控制點
P02,246450.000,2665050.000,52.820,控制點
```

各站依點號自動配對，測站窗格會顯示配對到的 GPS 點號。

- 同點號、相同座標組：只計一次，不增加權重。
- 同點號、不同座標組：不同組各取一次，平均形成一筆控制座標，並提示差異。
- 沒有任何測站觀測的 GPS 點，可作為 GPS-only 點列入合併匯出。
- 載入沒有共用 GPS 欄位的專案時，原各 GPS 測站清單會集中帶入。

## 4. 選擇平差模式並計算

確認輸入預覽與診斷後，在上方測站操作區的「平差模式」選擇一種方法，再按上方「新增測站」右邊的「計算並查看結果」。「平差模式」排列在「共同協調比例」之前。每次只計算所選模式，不再固定產生主解與參考解。

| 項目 | 保留內部幾何（預設） | 共同協調 |
| --- | --- | --- |
| 計算方式 | 先不使用 GPS 做內部聯測，再將各群組整體套合 GPS | GPS 與各站觀測同時參與平差 |
| 水平比例 | 全程固定 K＝1，不顯示比例控制 | 顯示「共同協調比例」，可選 K＝1 或開放比例 |
| GPS 作用 | 整體平移、旋轉與高程位移，保留內部平差完成後的幾何 | 以軟約束參與求解，可影響內部相對關係 |
| 獨立站 | 各自與對應 GPS 套合 | 各自與對應 GPS 求解 |
| 權重 | 內部聯測等權重；每個 GPS 點號作一筆套合控制 | 每筆 GPS 約束與每站觀測等權重 |

共同協調的精度權重設定尚未提供，後續才加入；目前不能輸入標準差或設定不同儀器精度權重。

保留內部幾何模式依「測站排列順序」判定測量區塊：相鄰前後站至少有兩個不同點號的共同點，才連成同一區塊；只有一個或沒有共同點，就從後站開始新區塊。重複列不算不同共同點。非相鄰站即使有同名點，也不會跨越已切開的邊界把區塊重新連接。

例如 S1／S2 有兩個共同點、S2／S3 只有一個、S3／S4 有兩個，則為 B1＝S1＋S2、B2＝S3＋S4。沒有聯測的單站也獨立形成區塊。

每個區塊各自完成內部聯測，再以 K＝1 套合該區塊對應的 GPS。每區塊至少需要兩個幾何上可定向的 GPS 控制點。無法初始化、未收斂、共同點幾何退化或 GPS 不足的區塊會明確顯示失敗，其他區塊仍可計算。這項分區規則僅用於保留內部幾何模式；共同協調模式維持原同名點聯合平差規則。

摘要列出 B1、B2 等區塊編號、所屬測站與邊界共同點數。區塊內同名點才合併；不同區塊的同名點分別保留，合併表、地圖與匯出以區塊編號及來源測站辨識，避免後一區塊覆蓋前一區塊。跨區塊不計為內部閉合差。

切換平差模式、修改已計算的輸入資料，或調整共同協調比例後，舊成果會清除並提示重新計算。計算完成後，表格、地圖、TSV、CSV 與 HTML 報告都使用本次所選模式。

## 5. 檢查成果與殘差

成果依序顯示「計算摘要 → 超限殘差檢核 → 合併座標與匯出 → 成果地圖 → 各站計算明細 → 詳細計算紀錄」。先檢查摘要與失敗訊息；保留內部幾何模式另須檢查摘要中的群組 GPS 套合 RMS。摘要會標示本次計算模式。

各站明細、殘差與詳細計算紀錄預設收合，需要時點開查看；失敗測站與群組狀態保持可見。E、N 與原有 X,Y 欄位皆保留。各模式原理與檢核門檻集中於設定區的「平差方法與精度說明」。

| 指標 | 意義 |
| --- | --- |
| 內部 RMS／SD、本站轉換 − 聯合座標 | 測站觀測與內部共同成果的吻合程度 |
| GPS 套合 RMS、聯合座標 − GPS | 主要成果與 GPS 控制座標的吻合程度 |
| 3D | 三方向差值平方和開根號，單位公尺 |

預設提示門檻：小於 0.020 m 為良好；0.020 m 至未滿 0.050 m 為注意；0.050 m 以上需檢核。GPS 套合 RMS 也會影響測站狀態。

內部誤差與 GPS 套合誤差應分開判讀。殘差代表資料吻合程度，不能直接當成實際定位精度。

### 殘差大於 0.020 m 的點

結果區直接列出超限明細，分成「GPS 殘差：聯合座標 − GPS」與「測站觀測殘差：本站轉換 − 聯合座標」。依未四捨五入的 3D 值嚴格大於 0.020 m 篩選，各類由大到小排列；剛好等於 0.020 m 不列入。

表格包含點號、測站、GPS 來源、ΔE、ΔN、ΔH、水平 2D 與 3D，單位公尺。同區塊同點號 GPS 在各站重複顯示的殘差合併為一筆，不同區塊分列並標示區塊編號，保留相關測站與來源；測站觀測逐站保留。可下載「超限殘差 CSV」，HTML 報告也會包含明細。載入已計算專案時會重建清單。

此清單僅供檢核，不自動剔除 GPS 或測站資料。內部聯測良好、少數 GPS 明顯偏離時，可優先檢查這些 GPS；若同點的測站觀測也不一致，應先核對點號與原始觀測。水平與高程差需分開檢視，不能只因 3D 超過 2 公分就認定 GPS 有錯。

確認需停用某點 GPS 時，先保留一份原專案，再從共用 GPS 清單移除該點所有 GPS 列，保留各站對該點的實際量測資料並重新計算。檢查其餘控制點的殘差、分布與定向條件；保留幾何模式每群組至少需兩個可定向的 GPS 點，僅達最低條件不代表具有足夠的錯誤辨識能力。請記錄排除原因，避免只為降低殘差反覆刪點。

## 6. 檢視 GIS 地圖

地圖顯示目前所選模式計算出的成果。使用右上角圖層控制切換底圖：

| 底圖 | 來源 |
| --- | --- |
| 台灣通用電子地圖（預設） | 國土測繪中心 EMAP |
| 正射影像 | 國土測繪中心 PHOTO2 |

- 底圖擇一顯示，不改變成果座標。
- GPS+EDM、GPS-only、EDM 點位圖層可分別開關。
- 同一頁面期間重建地圖會保留底圖選擇；重新開啟頁面回到電子地圖。底圖選擇不存入專案 JSON。
- 底圖與外部地圖套件需連網；座標計算在本機瀏覽器執行。

## 7. 匯出與儲存

| 操作 | 輸出內容 |
| --- | --- |
| 複製各站／合併 TSV、下載合併 CSV | 本次所選模式成果；可帶入 Excel 等後續作業 |
| 下載 HTML 報告 | 本次所選模式成果，並標示模式 |
| 儲存專案 JSON | 共用 GPS、測站資料、平差模式與本次成果、CAD 輸入與已套用的自訂對照等專案狀態 |

保留內部幾何的 CSV／HTML 檔名含 `geometry_K1`，共同協調含 `joint`。專案 JSON 儲存 `survey.adjustmentMode` 與當次成果，載入後恢復同一模式；不會自動保留另一模式的成果。

若要比較兩種模式，請先匯出一種，再切換模式重新計算並匯出另一種，透過檔名辨識。載入先前雙解專案時，使用原保留幾何成果；沒有模式標記的舊共同協調成果仍按共同協調顯示。請以目前版本頁面讀取存檔。

## 8. 匯出 AutoCAD Script

切換至「AutoCAD Script 匯出」，依需求貼入控制點與孔蓋資料。CAD 輸入使用實際貼入的資料，不會自動被所選平差模式的成果替換。

```text
控制點：點號 X Y Z
CP01 246440.000 2665050.000 52.250

孔蓋：點號 Code X Y [Z]
MH01 EMHX 246445.000 2665055.000 52.100
```

1. 確認目標 DWG 已有對應圖塊，並使用相同座標分帶與公尺單位。
2. 檢查 Code 對照與格式提示；需要時使用「Code 對照設定」展開編輯並套用，再按同一按鈕收合。格式錯誤與略過筆數會持續顯示在檢查摘要及匯出區。
3. 下載 `.scr`，儲存圖面後再於 AutoCAD 執行。

常用預設對照：`EMHX → 12-N-E`、`UMH → 20`、`UHH → 30`、`WMH → 98`、`CP → CPT`。

控制點及 `12-N-E` 圖塊以 X、Y 定位，點號與高程寫入 `CPTNAME`、`CPTELEV`。`98` 圖塊使用 0.5 插入比例。未對應 Code 會提示並略過，請先檢查再匯出。

已套用的自訂對照會嘗試儲存於目前瀏覽器；專案 JSON 另保留專案對照及編輯內容。
