圖塊對照與 AutoCAD 使用說明

執行前

目標 DWG 須先定義對應圖塊，並使用相同 TWD97 二度分帶、世界坐標系（WCS），繪圖單位為公尺。控制點 CPT 圖塊需有 CPTNAME、CPTELEV 屬性標籤。

內建 Code 對照

TMH → 11 · EMH → 12 · SM → 15 · RM → 16 · WV → 17 · GV → 18
F → 19 · UMH → 20 · THH → 21 · EHH → 22 · CP → CPT

圖層與腳本執行

圖層依序取同名既有圖塊參考的非 0 圖層、圖塊內第一個非 0 圖層、既有參考的 0 圖層，皆無則使用目前圖層。關閉或凍結的圖層可能讓圖塊不可見。

先儲存圖面，再將 .scr 拖入 AutoCAD。正常執行完成後會恢復原鎖點設定；腳本另會設定 ATTREQ、ATTDIA、CMDECHO，請依需要調回原值。
